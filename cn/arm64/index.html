Arm64中特别指令

曾经认为写汇编很无聊，但是工作中却感受不同，每个汇编代码的实现，就像是告诉机器如何执行、按如何规程来执行代码，这比告诉对接人需要的接口，或者告诉对接人自己实现的接口要轻松很多。
目录

之前在写5级流水线cpu时，写了一些mips汇编，所以指令都比较少，在模版解释器工作中，arm64汇编模版中有很多类似的指令，但是有许多单指令多作用的便捷指令，我认为值得记录下来，下面是我在编写中用到的比较好用的汇编指令。写这篇记录的主要原因是告诫自己（其实是其他人），“眼界宽些，尊重他人观点表达”。

1.cset(condition set)

set:cond成立->rd=1,cond不成立->rd=0
适用场景主要是比较判断后需要根据判断结果来设置0、1值，还有个比较类似的csel，它不设立特殊值，而是根据cond选择寄存器进行类似mov的操作，之后我会记录该指令。

2.fneg

这个指令是OP_neg中用到的，作用是对浮点数取相反数，曾经写mips汇编多用zero寄存器sub去rt得到rd，从而实现相反数，果然arm64指令集充分。有意思的是对于JS中-0.0有特殊用处，console.log(1/0.0)结果为Infinity，console.log(1/-0.0)结果-Infinity，-0.0的IEEE754位模式为1<<63，对于int32_min的相反数，显然溢出32为有符号整数，参考反汇编发现#0x41e0000000000000 是-int32_min的IEEE754 位模式。

3.tbz & tbnz

用来测试寄存器某位是否为0或非零，是则跳转，否则继续执行。tbnz w8, #31, Lnext这行代码表示w8如果第31位非0则跳转，实际就是w8为负数就跳转。

4.ccmp

又是否或逻辑分支可以无需多次冗余cmp，利用ccmp设置NZCV会很方便
cmp w1, #2 ; 比较 w1（存储 tag 值）和 #2（JS_TAG_NULL）
; 若相等 → Z=1，否则 Z=0

ccmp w1, #3, #4, ne ; 条件比较：
; 当上条指令结果不相等（ne）时：比较 w1 和 #3（JS_TAG_UNDEFINED）
; - 若相等 → Z=1，否则 Z=0
; 当上条指令结果相等时：强制设置标志位为 #4（二进制 0100 → Z=1）

b.eq handle_null_or_undefined ; 若 Z=1 则跳转
与C代码的对应关系
if (tag == JS_TAG_NULL || tag == JS_TAG_UNDEFINED)
分支触发场景：

  1. 当 tag == 2 (JS_TAG_NULL)：
    • cmp 设置 Z=1
    • ccmp 强制设置 Z=1（因上条指令已满足相等）
    • b.eq 触发跳转 → 执行 if 分支
  2. 当 tag == 3 (JS_TAG_UNDEFINED)：
    • cmp 设置 Z=0（不相等）
    • ccmp 比较后设置 Z=1（因 tag==3）
    • b.eq 触发跳转 → 执行 if 分支
  3. 其他值（如 tag=1/4/5…）：
    • cmp 设置 Z=0
    • ccmp 比较后设置 Z=0（因 tag≠3）
    • b.eq 不跳转 → 执行 else 分支
      注：此设计通过条件标志位操作，避免了冗余比较指令，是ARM架构下高效实现逻辑或（||）的典型优化方案。

5.cbz

寄存器为0跳转

6.csel

条件选择，使用该指令则无需跳转来分情况赋值，原地选择即可。
cmp w8, #0x0 ;判断是否strict
mov w8, #0x8000 ;flags = JS_PROP_THROW_STRICT;
mov w9, #0x18000 ;flags |= JS_PROP_NO_ADD;
csel w7, w9, w8, ne

7.ldur、ldr

取内存指令load，实际上使用很频繁，但是有时为了一条load指令同时实现帧的移动，比如后变址ldr x0, [x20], #-0x10，load后地址自减10，等价于ldur x0, [x20]\n sub x20, x20, #0x10，ldur的u是unscaled表示非对齐，ldur无法使用前后变址，如ldr x0, [x20,#-0x10]!。

8. sxtw

我写的一条指令出了bug，主要来说是ldrsb到w寄存器，导致高位为0，形成很大的正数，实际上ldrsb到x寄存器即可，但是cr人员使用sxtw来符号扩展，属于多此一举，今天又在一条指令中发现了它，
add x0, x20, w1, sxtw #4,x20是sp，所以w1中存了偏移量，而sp中两个字节指向一个JSValue，所以需要符号扩展w1偏移量，同时左移4位。这条指令是Sign extend to Word。下面是模版，其中有些关于位运算优化，如德摩根、补码编译器优化。值得学习。身为programmer，熟悉负数补码特性就像熟悉指数对数转换一样。

9.adr和adrp

adr x0, label获得address of label，主要是为了获取数据段的值，下面是个adr的例子，需要字符串时，实际是获取字符串指针，即字符串所在地址。也可以用adrp x0, page，获取page的地址后，利用add x0, x0,值所在页偏移获得地址。
